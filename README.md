# bw_auto_ignore

StarCraft: Remastered 외부 오버레이 도구입니다.  
상대방 전적 자동 조회, 채팅 무시, 스페이스바 컨트롤 키 대체 기능을 제공합니다.

## 기능

- **전적 자동 조회**: 게임 시작 시 상대방의 래더 전적(티어·점수·종족·연승/연패)을 자동으로 조회해 오버레이에 표시
- **채팅 무시**: 현재 대전 상대의 채팅을 한 키로 차단/해제
- **스페이스바 → 컨트롤**: 스페이스바를 컨트롤 키로 사용 (설정에서 켜기/끄기)
- **맵 이름 표시**: 현재 맵 이름을 오버레이에 표시

## 단축키

| 키 | 기능 |
|----|------|
| F12 | 전적 오버레이 GUI 켜기/끄기 |
| F9 | 상대방 채팅 무시 (`/ignore`) |
| F8 | 채팅 무시 해제 (`/unignore`) |
| Space | 컨트롤 키 대체 (설정 ON 시) |

## 오버레이 표시 정보

| 컬럼 | 설명 |
|------|------|
| GW | 게이트웨이 (KR / Asia / USW / USE / EU) |
| 아이디 | 인게임 이름 |
| 현재 시즌 | 티어 + 점수 + 시즌 번호 |
| 종족 | 주력 종족 (Z / T / P) |
| 역대 최고 | 역대 최고 티어 + 점수 |
| 연속 | 연승(파란색) / 연패(빨간색) |
