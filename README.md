# SCR Scout

[English](README.en.md) | 한국어

> StarCraft: Remastered 인게임 오버레이 — 상대방 전적 자동 조회부터 채팅 차단까지, 게임에 집중하세요.

[Download (.exe)](https://github.com/IkbeomJeon/scr_scout/raw/main/dist/scr_scout.exe) | Visual Studio 2022 x64 직접 빌드 가능

## 기능

![main](img/main.png)

### 1. 전적 자동 조회

게임이 시작되면 상대방의 **모든 아이디(부캐 포함)** 를 자동으로 검색해 티어, 점수, 종족, 연승/연패를 오버레이로 보여줍니다.  
부캐로 낮은 티어 유저를 사냥하는 **양학 유저** 를 바로 잡아내세요.

- 티어 표: GW / 아이디 / 종족(색상) / 현재 티어 / 최고 티어 / 연승·연패
- 상대 종족별 승률 표(최근 100경기): Total(전체) + T/P/Z별 게임 수 및 승률 바

### 2. 채팅 자동 무시

**F9** 한 번으로 상대방 채팅을 즉시 차단합니다. 욕설, 심리전에 흔들리지 말고 게임에만 집중하세요.  
트레이 설정에서 **게임 시작 시 자동 차단** 을 켜두면 매번 누를 필요 없이 자동으로 적용됩니다.

### 3. 맵 이름 표시

맵 이름을 오버레이 상단에 표시해 **입구 방향이 헷갈리는 맵** 도 바로 파악할 수 있습니다.

### 4. 스페이스바 → 컨트롤 키

손이 닿기 어려운 **7, 8, 9, 0번**을 스페이스바로 손쉽게 부대지정하세요.

### 5. 인게임 귓말 빠른 답장

인게임에서 귓말을 받은 뒤 **Shift+Enter**를 누르면 채팅창에 `/w 발신자아이디 `가 자동으로 입력됩니다.  
발신자 아이디를 직접 타이핑할 필요 없이 바로 답장을 이어서 쓸 수 있습니다.

## 단축키

| 키 | 기능 |
|----|------|
| F12 | 전적 오버레이 켜기/끄기 (켠 상태면 계속 유지) |
| F9 | 상대방 채팅 무시 |
| F8 | 채팅 무시 해제 |
| Shift+Enter | 마지막 귓말 발신자에게 빠른 답장 (인게임) |

## 세부 설정

시스템 트레이 아이콘 우클릭 → Setting

| 설정 | 설명 |
|------|------|
| Auto-display stats (10s) | 게임 시작 시 전적 오버레이를 10초간 자동 표시 |
| Auto-ignore on game start | 게임 시작 시 상대 채팅 자동 차단 |
| Swap Space/Control | 스페이스바를 컨트롤 키로 전환 |
| Whisper reply (Shift+Enter) | 귓말 빠른 답장 활성화 |

## Windows 보안 경고에 대해

프로그램 실행 시 *"Windows에서 PC를 보호했습니다"* 또는 *"신뢰할 수 없는 앱"* 경고가 표시될 수 있습니다.

이는 **코드 서명 인증서**(유료)가 없어서 발생하는 현상으로, 프로그램 자체에 문제가 있는 것이 아닙니다.  
이 프로그램의 **모든 소스 코드는 이 저장소에 공개**되어 있으며, 누구나 직접 빌드해서 사용할 수 있습니다.

실행하려면 경고 창에서 **"추가 정보" → "실행"** 을 클릭하세요.
