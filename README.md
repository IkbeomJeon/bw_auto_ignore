# SCR Scout

[English](README.en.md) | 한국어

> StarCraft: Remastered 인게임 오버레이 — 상대방 전적 자동 조회부터 채팅 차단까지, 게임에 집중하세요.

---

## 기능

![main](img/main.png)

### 1. 전적 자동 조회

게임이 시작되면 상대방의 **모든 아이디(부캐 포함)** 를 자동으로 검색해 티어, 점수, 종족, 연승/연패를 오버레이로 보여줍니다.  
부캐로 낮은 티어 유저를 사냥하는 **양학 유저** 를 바로 잡아내세요.

### 2. 채팅 자동 무시

**F9** 한 번으로 상대방 채팅을 즉시 차단합니다. 욕설, 심리전에 흔들리지 말고 게임에만 집중하세요.  
트레이 설정에서 **게임 시작 시 자동 차단** 을 켜두면 매번 누를 필요 없이 자동으로 적용됩니다.

### 3. 맵 이름 표시

맵 이름을 오버레이 상단에 표시해 **입구 방향이 헷갈리는 맵** 도 바로 파악할 수 있습니다.


### 4. 스페이스바 → 컨트롤 키

손이 닿기 어려운 **7, 8, 9, 0번**을 스페이스바로 손쉽게 부대지정하세요.

## Windows 보안 경고에 대해

프로그램 실행 시 *"Windows에서 PC를 보호했습니다"* 또는 *"신뢰할 수 없는 앱"* 경고가 표시될 수 있습니다.

이는 **코드 서명 인증서**(유료)가 없어서 발생하는 현상으로, 프로그램 자체에 문제가 있는 것이 아닙니다.  
이 프로그램의 **모든 소스 코드는 이 저장소에 공개**되어 있으며, 누구나 직접 빌드해서 사용할 수 있습니다.

실행하려면 경고 창에서 **"추가 정보" → "실행"** 을 클릭하세요.
