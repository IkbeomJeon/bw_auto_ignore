# bw_auto_ignore

> StarCraft: Remastered 인게임 오버레이 — 상대방 전적 자동 조회부터 채팅 차단까지, 게임에 집중하세요.

[Download (.exe)](https://github.com/ikbeomjeon/bw_auto_ignore/raw/main/dist/bw_auto_ignore.exe) | Visual Studio 2022 x64 직접 빌드 가능

---

## 기능

![main](img/main.png)

### 1. 전적 자동 조회

게임이 시작되면 상대방의 **모든 아이디(부캐 포함)** 를 자동으로 검색해 티어, 점수, 종족, 연승/연패를 오버레이로 보여줍니다.  
부캐로 낮은 티어 유저를 사냥하는 **양학 유저** 를 바로 잡아내세요.

### 2. 채팅 자동 무시

**F9** 한 번으로 상대방 채팅을 즉시 차단합니다. 욕설, 심리전에 흔들리지 말고 게임에만 집중하세요.  
트레이 설정에서 **게임 시작 시 자동 차단** 을 켜두면 매번 누를 필요 없이 자동으로 적용됩니다.

### 3. 맵 이름 표시

맵 이름을 오버레이 상단에 표시해 **입구 방향이 헷갈리는 맵** 도 바로 파악할 수 있습니다.


### 4. 스페이스바 → 컨트롤 키

손이 닿기 어려운 **7, 8, 9, 0번**을 스페이스바로 손쉽게 부대지정하세요.


### 5. 귓말 빠른 답장

**Shift+Enter** 를 누르면 가장 최근에 귓말을 보낸 상대의 아이디로 `/w 아이디 ` 가 자동 입력됩니다.  
채팅 창이 닫혀 있으면 자동으로 열고 입력해줍니다. 트레이 설정에서 활성화할 수 있습니다.

## 단축키

| 키 | 기능 |
|----|------|
| F12 | 전적 오버레이 켜기/끄기 |
| F9 | 상대방 채팅 무시 |
| F8 | 채팅 무시 해제 |
| Shift+Enter | 귓말 빠른 답장 (설정에서 활성화 시) |

## 세부 설정

시스템 트레이 아이콘 우클릭 → Setting
